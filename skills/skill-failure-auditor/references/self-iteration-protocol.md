# 技能自我迭代要求

本文件用于“以目标技能评测并改进目标技能”的场景，不授权技能审计自身后接受自身。

## 固定顺序

1. 冻结公开评测规格、验收标准承诺、最大轮次和角色权限。
2. 为每轮创建新的评测任务、尝试编号、进程和用例隔离区。
3. 目标技能只接收公开评测包，不接收隐藏期望或可逆线索。
4. 目标技能退出后先封存原始证据。
5. 独立评分器读取封存的验收标准并生成白名单评分结果。
6. 清理全部用例隔离区并验证清理证明。
7. 全新只读职责执行主动推翻式语义审阅。
8. 失败归因后才允许修复；修复者不能读取隐藏的验收标准。
9. 复测创建新的任务、尝试、进程、隔离区、评分和审阅。
10. 达到最大轮次仍不通过时输出 `BLOCKED` 或 `NEEDS_INPUT`，不得放宽标准。

## 能力声明

在使用运行时前核验其真实代码是否实现：

- 验收标准单向提交、提交后对执行者不可读；
- 不同操作系统身份的评分职责；
- 逐用例 HOME、TMP、缓存、工作区和进程隔离；
- 真实写集与工具边界；
- 外部最终裁决。

若只有 Schema、测试夹具或文档描述，所有结果标为 `acceptance_eligible: false`。

## 自审状态

目标技能审计自身时只能输出：

```text
SELF_AUDIT_SUBMITTED_FOR_EXTERNAL_REVIEW
```

该结果不能作为最终通过依据。
