# 失效模式分类索引（FM-01 至 FM-28）

机器唯一事实源为同目录下的 `failure-modes.jsonl`（受 `builtin-registry-lock.json` 摘要锁定）；本表仅供快速查阅各编号对应的失效维度与直观含义，详细触发条件、必查证据与反证规则以 `failure-modes.jsonl` 为准。

| 失效维度 | 编号 | 失效模式中文名称 | 核心必查红线 |
|---|---|---|---|
| 目标对齐 | FM-01 | 自己宣布完成就算通过 | 是 |

| 自评估 | FM-07 | 没人对最终结果负责 | 否 |
| 上下文可靠性 | FM-08 | 关键要求只在一个地方提了一次 | 否 |

11 条核心必查红线由 `registry_tool.py` 的 `CORE_REDLINES` 常量与 `failure-modes.jsonl` 中的 `core_redline: true` 双重强制锁定，任何路由筛选或容量裁剪均不得将其剔除。
